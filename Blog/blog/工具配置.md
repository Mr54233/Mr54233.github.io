# 工具配置

推荐使用IDE为Vscode

推荐安装以下插件以提升效率

  

- [Iconify IntelliSense](https://marketplace.visualstudio.com/items?itemName=antfu.iconify) - Iconify 图标插件

  - 可以在代码编辑器（如 VSCode）中提供 Iconify 的智能提示，支持直接搜索和插入图标，兼容 Unocss 和其他图标方案，让 Vue 项目中的图标管理更加便捷。
- [unocss](https://marketplace.visualstudio.com/items?itemName=antfu.unocss) - unocss 提示插件

  - 提供 UnoCSS 的智能提示和自动补全，支持类名预览，能够提升开发体验，尤其适用于喜欢 Tailwind 语法风格的用户。
- [I18n-ally](https://marketplace.visualstudio.com/items?itemName=Lokalise.i18n-ally) - i18n 插件

  - 支持 Vue i18n 和其他国际化方案，提供多语言文件管理、键值提示、快速跳转等功能，大幅提高国际化开发的效率。
- [Vue - Official](https://marketplace.visualstudio.com/items?itemName=vue.volar) - vue 开发必备插件

  - 官方维护的 Vue 3 插件，提供 Vue 组件语法高亮、模板自动补全、Vue 语法检查等功能，是 Vue 开发环境的基础插件。
- [ESLint](https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint) - 代码静态检查

  - 确保 JavaScript/TypeScript 代码符合规范，能够自动修复部分代码问题，帮助保持代码风格一致，并减少潜在错误。
- [Prettier](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode) - 代码格式化

  - 支持自动格式化 JavaScript、TypeScript、Vue 模板、CSS 等文件，搭配 ESLint 使用可以更好地规范代码风格，提高可读性。
- [Stylelint](https://marketplace.visualstudio.com/items?itemName=stylelint.vscode-stylelint) - CSS 格式化

  - 专门用于检查和格式化 CSS/SCSS/LESS 代码，能够帮助发现并修复样式代码中的问题，确保样式代码的一致性。
- [DotENV](https://marketplace.visualstudio.com/items?itemName=mikestead.dotenv) - .env 文件高亮

  - 让 `.env` 配置文件在代码编辑器中拥有更好的语法高亮支持，提升可读性，避免错误修改环境变量。
- [SonarQube for IDE](https://marketplace.visualstudio.com/items?itemName=SonarSource.sonarlint-vscode) - sonar 本地静态检测

  - 集成 SonarQube 代码质量检测工具，可在开发阶段提前发现潜在的代码安全问题和质量缺陷，适用于代码审查和质量保障。
