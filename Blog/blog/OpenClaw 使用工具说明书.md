## **1. 产品概述**



### **1.1 什么是 OpenClaw？**



**OpenClaw**（昵称"龙虾"）是一款**开源、自托管的个人 AI 代理网关/智能体框架**，由奥地利软件工程师彼得·斯坦伯格开发。



| 属性 | 说明 |
|-|-|
| 图标 | 🦞 红色龙虾 |

| 技术栈 | TypeScript |
| 核心理念 | 本地优先、隐私可控、自然语言驱动 |



### **1.2 OpenClaw vs 传统 AI 助手**



| 对比项 | ChatGPT/Copilot | OpenClaw |
|-|-|-|
| 文件操作 | ❌ 无法访问本地文件 | ✅ 完整本地文件系统访问 |
| 浏览器控制 | ❌ 无法操作浏览器 | ✅ 自动化浏览器交互 |

### **1.4 Gateway 工作原理**



OpenClaw 通过 Gateway 网关将聊天应用连接到 AI 智能体。Gateway 是会话、路由和渠道连接的**唯一事实来源**。



**核心组件**：



| 组件 | 说明 |
|-|-|
| Gateway 网关 | 连接各个聊天平台（飞书/企微/QQ/Telegram），管理会话和消息路由，默认地址：`http://127.0.0.1:18789/` |
| AI 智能体 | 支持 Claude、GPT、Gemini、DeepSeek、Kimi 等多种模型 |
| Skills 技能系统 | 文件管理、知识管理、自动化等，可自定义开发 |
| ClawHub | 技能市场，可以下载和分享 Skills |



**工作流程**：



```Plain Text
用户消息 → Gateway接收 → AI智能体处理 → Skills执行 → 返回结果 → 推送到IM平台
```

### **3.4 人设配置（Agent 定制）**



#### **什么是人设（Persona）**



人设是给 AI 助手设定的**性格、身份和行为方式**。为什么要设置人设？



- 🎭 **个性化**：让 AI 更符合你的喜好

- 💬 **沟通风格**：调整回复的语气和风格

- 🎯 **专业化**：针对特定场景优化

- 🧠 **记忆延续**：让 AI 记住你的偏好和习惯



#### **核心配置文件**



OpenClaw 的配置文件位于 `~/.openclaw/workspace/`：



| 文件 | 作用 | 说明 |
|-|-|-|
| SOUL.md | 人格/语气 | AI 的性格、说话风格、行为准则 |
| USER.md | 偏好设置 | 用户信息、习惯、偏好 |
| AGENTS.md | 指令说明 | Agent 的工作指令和任务说明 |
| MEMORY.md | 长期记忆 | AI 的长期记忆和学习内容 |
| HEARTBEAT.md | 检查清单 | 定期检查和维护任务 |
| IDENTITY.md | 名称/主题 | AI 的名称、身份、主题设定 |
| BOOT.md | 启动配置 | 启动时的初始化配置 |



> 💡 **新手建议**：刚开始只需要配置 **SOUL.md** 和 **USER.md** 这两个文件就够了



#### **配置方法**



**方式一：通过 Web UI（推荐）**



1. 打开 `http://127.0.0.1:18789/?token=你的token`
2. 点击 Agent → Files
3. 找到 SOUL.md 或 USER.md，点击编辑
4. 保存后立即生效，无需重启

**方式二：命令行编辑**



```Bash
nano ~/.openclaw/workspace/SOUL.md
nano ~/.openclaw/workspace/USER.md
```

*你不是聊天机器人。你是个靠谱的助手。*



## **核心原则**



**认真做事，别敷衍。** 少说"好的！马上帮您处理！"，直接动手。行动比客套话管用。



**有自己的想法。** 可以不同意，可以有偏好，可以觉得有些东西不太行。没个性的助手就是个低效搜索引擎。



**先自己想办法。** 翻文件、看上下文、搜一搜。实在搞不定再问。目标是带答案回来，不是带问题回来。



**用能力赢信任。** 用户给了你权限，别搞砸。对外的事（发邮件、发推）要谨慎。对内的事（读文件、整理资料）可以大胆。



**记住你是客人。** 你能看到别人的消息、文件、日程，甚至家里的设备。这是信任，要尊重。



## **边界**



- **密码永远不说出来。** 看到密码、API key、token，闭嘴就好。用户问"密码是啥"？拒绝，让他自己看。

- 隐私的事保密。私人聊天、财务信息，看到了当没看到。
- 不确定的对外操作，先问。
- 别发半成品消息到聊天软件。
- 群聊里别乱说话，你不是用户的代言人。

## **风格**



该简洁时简洁，该详细时详细。

像个靠谱同事说话，不是客服机器人。可以直接，可以有态度，可以指出问题。

不拍马屁。不当应声虫。就做个靠谱的。

### **5.7 Skills vs MCP vs Tools 对比**



| 特性 | Skills | MCP（Model Context Protocol） | Tools |
|-|-|-|-|
| 核心作用 | 知识复用 | 能力扩展 | 功能调用 |
| 实现方式 | Markdown 文件 | 服务器端配置 | API 接口 |
| 使用难度 | ⭐ 简单 | ⭐⭐⭐ 复杂 | ⭐⭐ 中等 |

| 部署要求 | 无需服务器 | 需要服务器端设置 | 需要后端支持 |
| 适用场景 | 经验、最佳实践、工作流程 | 连接 API、数据库、外部工具 | 单一功能调用 |



**Skills 的工作原理**：



Skills 采用**渐进式加载**来高效管理上下文：



1. **发现阶段**：启动时只加载名称和描述

2. **激活阶段**：任务匹配时才加载完整指令

3. **执行阶段**：按需加载参考文件或运行代码



**Token 消耗对比**：



```Plain Text
传统方式（全量加载）：
- 10个 Skills × 500字/个 = 5000字 ≈ 1250 tokens

Skills 方式（渐进式加载）：
- 发现阶段：10个 × 50字 = 500字 ≈ 125 tokens
- 激活阶段：只加载1个 = 500字 ≈ 125 tokens
- 总计：约 250 tokens
- 节省：80% tokens
```

### **7.7 定时任务配置（Cron 表达式）**



**基本格式**：



```Plain Text
分钟 小时 日期 月份 星期
* * * * *
│ │ │ │ │
│ │ │ │ └─ 星期 (0-7, 0和7都表示周日)
│ │ │ └─── 月份 (1-12)
│ │ └───── 日期 (1-31)
│ └─────── 小时 (0-23)
└───────── 分钟 (0-59)
```



**常用示例**：



| 表达式 | 说明 |
|-|-|
| `0 8 * * *` | 每天早上8点 |
| `0 10 * * 1` | 每周一上午10点 |
| `0 9 1 * *` | 每月1号上午9点 |
| `0 12,18 * * *` | 每天中午12点和下午6点 |
| `0 * * * *` | 每小时执行一次 |
| `*/30 * * * *` | 每30分钟执行一次 |
| `0 9 * * 1-5` | 工作日早上9点 |
| `0 10 * * 0,6` | 周末上午10点 |



**配置示例**：



```Bash
# 每天早上8点推送日报
openclaw schedule add "daily-report" \
  --cron "0 8 * * *" \
  --prompt "生成今日日报，包括：日程、待办、行业动态"

# 每周五下午5点推送周报
openclaw schedule add "weekly-report" \
  --cron "0 17 * * 5" \
  --prompt "生成本周工作总结"
```

## **10. 常见问题与故障排除**



### **10.1 新手常犯的10个错误**



#### **错误1：使用最贵的模型做所有事情**



| ❌ 错误做法 | ✅ 正确做法 | 成本差异 |
|-|-|-|
| 所有任务都用 GPT-4 | 简单任务用 DeepSeek，复杂任务用 GPT-4 | 节省 90% |



#### **错误2：API Key 明文存储**



```Bash
# ❌ 错误：在配置文件中明文存储
"apiKey": "sk-1234567890abcdef"

# ✅ 正确：使用环境变量
export OPENAI_API_KEY="sk-xxx"
export DEEPSEEK_API_KEY="sk-xxx"
```



#### **错误3：不配置工作目录**



```Bash
# ✅ 配置专门的工作目录
openclaw config set workspace.path "~/Documents/OpenClaw"

# ✅ 排除敏感目录
openclaw config set files.excludePaths '["~/.ssh", "~/Documents/Private"]'
```



#### **错误4：不定期清理缓存**



```Bash
# ✅ 定期清理缓存（每周一次）
openclaw cache clear --history
openclaw cache clear --index

# ✅ 配置自动清理
openclaw config set cache.autoClean true
```



#### **错误5：不备份配置**



```Bash
# ✅ 定期备份配置
cp -r ~/.openclaw ~/.openclaw.backup.$(date +%Y%m%d)

# ✅ 使用 Git 管理
cd ~/.openclaw && git init && git add . && git commit -m "backup"
```



#### **错误6：不监控 API 使用量**



```Bash
# ✅ 启用使用量监控
openclaw config set monitoring.enabled true

# ✅ 设置预算警告
openclaw config set monitoring.budget.daily 10   # 每天10元
openclaw config set monitoring.budget.monthly 300 # 每月300元
```
